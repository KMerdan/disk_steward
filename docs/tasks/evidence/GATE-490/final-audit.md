# GATE-490 final product audit

The independent final increment test starts the built menu bar executable in UI-smoke mode and verifies accessory/launched state. It captures a live volume snapshot, exercises the human board and snapshot export, round-trips watched/excluded roots and retention settings, scans a real temporary watched folder, omits an excluded subtree, and creates an exact process/file/task provenance fixture with typed causal references.

The same test denies optional permissions and confirms standard monitoring plus unknown fallback, property-checks sensitive metadata removal, persists and integrity-checks evidence, exports a basename-only evidence bundle with SHA-256 verification, launches the built MCP connector against the private Unix socket, confirms the seven read-only tools and a provenance query, rejects forbidden privacy keys, validates a healthy declared resource measurement, and proves stopped-service recovery fails closed.

## Human UX checklist

- Left click routes to the compact status board; right click routes to the utility menu.
- The menu bar app launches without a Dock presence and reports ready in smoke mode.
- Snapshot values are live and current evidence export is reachable.
- Watched and excluded roots plus retention limits survive settings reload.
- Permission denial says standard monitoring remains active and exact provenance is unavailable.
- Cleanup remains review-only; MCP exposes no delete tool.

## Fallback and residual limitations

- Exact attribution is proven through the normalized privileged fixture path only. No Apple entitlement, valid signing identity, system-extension activation, Full Disk Access approval, or live Endpoint Security event was available on this host.
- The unsigned development candidate is build/test evidence, not a distributable release. Release preflight remains blocked until real team identifiers, provisioning, Developer ID signing, notarization, and clean-host activation/uninstall tests exist.
- Performance evidence proves deterministic queue/history bounds, complete loss accounting, and declared-budget evaluation. Idle/load CPU and resident memory must be measured again on the signed release artifact.
