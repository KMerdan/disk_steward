# Disk Steward 1.2.2

## A dashboard that stays current

- Capacity and Recent change now update together as new samples arrive.
- Growth uses comparable samples from the same volume, including decreases.
- Growth no longer waits for the detailed file scan to finish. Capacity and file-detail freshness are shown separately.
- The latest growth alert retains its original amount and time interval, even when the next sample shows a smaller change.
- Refresh requests a real sample, with overlapping requests coalesced safely.

## Distribution and compatibility

**Version 1.2.2 (build 7)** is a universal Apple Silicon / Intel app for macOS 13 or later, Developer ID signed, notarized by Apple, and stapled. The exact ZIP passed signature, Gatekeeper, notarization-ticket and isolated-startup checks after extraction.

This is a focused hotfix based on 1.2.1. It preserves schema-14 evidence and excludes the unfinished object-scanning/schema-15 work on `main`. Existing evidence and settings are not reset. File-detail coverage can still be partial while scanning continues.

Verification: 575 local Swift tests, 5 intentional opt-in skips, zero failures; signed-app startup and read-only MCP helper checks passed. Development CI on older Xcode still has separate concurrency-compatibility follow-up work; no green-CI claim is made for this release.

### Homebrew

Existing installation:

```sh
brew update
brew upgrade --cask disk-steward
```

New installation:

```sh
brew trust KMerdan/disk-steward
brew tap KMerdan/disk-steward
brew install --cask disk-steward
```

Trust the third-party tap only if you intend to accept its current and future casks.
