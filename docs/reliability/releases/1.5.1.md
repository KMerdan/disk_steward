# Disk Steward 1.5.1

## Current MCP clients, an evidence skill for both agents, and the fixes found in use

Version **1.5.1 (build 13)** supersedes 1.5.0.

### Fixed

- **Rust `target` folders are build output.** Cargo marks `target/` as a
  cache, so 1.5.0 listed these folders as downloadable caches with no
  rebuild command. With `Cargo.toml` beside it, a `target` folder is now
  build output that `cargo build` recreates. Review a folder again to update
  its stored items.
- **No contradictory advice.** An item with no known rebuild command no
  longer also says "It can be rebuilt from source". This applies to reviews
  you already have as well.
- **Agents can name a review scope as `get_health` shows it.** For example,
  `list_review_items` with `scope: "localGit"`. A name that matches nothing,
  or matches two scopes, lists the names that work instead of answering
  "no review".
- **`explain_growth` honours `limit`** for its list of changed folders.
- **Ordinary names are no longer redacted.** A folder such as
  `.disk-steward-backup` stayed partly hidden because it contains `sk-`.
- **Exported evidence bundles redact `password=s…` values.** The bundle
  exporter's filter skipped any credential value that began with the letter
  `s`; the corrected filter is shared with the agent answers.
- **The integration templates point at the real helper.** The Claude
  template and README and the Codex fragment named
  `Contents/MacOS/disk-witness-mcp`; the helper is in `Contents/Helpers`.

### For agents (MCP)

- **Newer protocol versions.** The helper speaks MCP `2026-07-28` (the
  stateless revision, discovered with `server/discover`) as well as
  `2025-11-25` and `2025-06-18`. Each client uses the newest version it
  supports. Responses are checked against the official MCP schemas.
- **Typed answers.** Every tool has a display title and an `outputSchema`
  that its answers match.
- **Correctable errors.** Arguments that break a tool's rules come back as a
  tool error the model can read and fix. Every error's details (code,
  message, recovery) are in its text.
- **The server says which build it is.** It reports the app's version, so a
  session still running an old helper is visible.

### For Codex and Claude Code

- **The app installs the evidence skill.** **Settings › Agent Integrations**
  now installs it with the server, for Codex in `~/.codex/skills` and for
  Claude Code in `~/.claude/skills`. The skill tells an agent how to read
  the evidence and how to clean up safely. It is removed with the
  integration only if you have not edited it.
- **One server name.** The source-checkout script (`Scripts/Integration/install`)
  now registers `disk-steward`, the same name the app uses, and never adds
  a second one beside the app's. Running it again migrates a 1.5.0 install.
  It no longer pins a tool list.

### After upgrading

Open **Settings › Agent Integrations** and press **Repair** for each agent
you use. This points the integration at the new helper and installs the
evidence skill. Then start a new agent session.

### Going back to 1.5.0

The store format is unchanged. Quit Disk Steward, then install 1.5.0 from
the [v1.5.0 release](https://github.com/KMerdan/disk_steward/releases/tag/v1.5.0).
